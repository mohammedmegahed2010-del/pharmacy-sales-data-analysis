# 🏥 Pharmacy Data Analytics & Operations Optimization

Welcome to the **Pharmacy Data Analytics** repository. This project is a comprehensive data science and analytics pipeline designed to optimize pharmacy performance, predict operational costs, streamline inventory, and improve staffing efficiency using advanced data manipulation and interactive visualizations.

By bridging data engineering with clinical and pharmaceutical domain knowledge, this repository provides data-driven answers to core challenges faced by modern pharmacy owners and managers.

---

## 📂 Repository Structure & Modules

The project is structured into specialized modules, each targeting a specific area of pharmacy management:

### 📊 [01. Pharmacy Sales Insights](./01-pharmacy-sales-insights)
- **Core Stack:** Python, Pandas, Plotly Express
- **Focus:** Analyzing transaction-level sales data to discover peak operational hours, identify high-demand drug categories (e.g., Paracetamol), optimize employee shifts, and manage safety stock levels to minimize shelf expiration and product stockouts.
---

## 🛠 Tech Stack Overview
- **Programming Language:** Python (3.x)
- **Data Engineering & Cleaning:** Pandas, NumPy
- **Dynamic Data Visualization:** Plotly Express
- **Interactive Notebooks:** Jupyter Notebook / NBViewer

---

## 🚀 Key Business Goals Addressed
1. **Reduce Labor Overheads:** Pinpointing exact quiet periods to scale back unnecessary late-night staffing.
2. **Optimize Inventory Turnover:** Highlighting fast-moving items to place strategically for zero customer delays.
3. **Data-Driven Procurement:** Moving away from guessing and utilizing predictive metrics for medication reorder points.
